# Документация

API и конфигурации сверены с официальной документацией 25 октября 2026 года. Версии, заявленные в package.json, не следует путать с фактически установленными: установка зависимостей в среде подготовки была недоступна. После первого успешного npm install сохраните package-lock.json.

- Vite: запуск, сборка и base — https://vite.dev/guide/ и https://vite.dev/guide/static-deploy
- Vitest: окружения, мокирование и отчёты — https://vitest.dev/config/environment и https://vitest.dev/guide/mocking и https://vitest.dev/guide/reporters
- React Testing Library — https://testing-library.com/docs/react-testing-library/api/
- Playwright: локальный сервер тестов — https://playwright.dev/docs/test-webserver
- GitHub Pages: статический хостинг — https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- Actions и метаданные Pages — https://github.com/actions/configure-pages и https://github.com/actions/deploy-pages

Основной источник требований — приложенные задание и лекция. Современная документация используется для актуального API и инструментов, а не для замены содержания задания. Сопоставление реализации с требованиями приведено в REQUIREMENTS.md.
